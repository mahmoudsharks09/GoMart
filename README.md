# GoMart

GoMart is a modern React e-commerce storefront built with Vite, Bootstrap, and React Bootstrap. The app includes a home page, product catalog, categories, cart, authentication flow, and an admin dashboard for product management.

## Project Overview

This project was designed as a complete storefront for a shopping app using product data from the DummyJSON API. It includes:

- Product listing and filtering
- Category browsing
- Product detail pages
- Cart and quantity management
- Login and role-based access
- Admin dashboard with CRUD actions
- User management and authentication views

## Features

- Responsive shopping layout
- Category-based browsing
- Product search and filtering
- Cart updates with total calculation
- Role-based access for Admin, Moderator, and Tester users
- Dashboard for product management and user information
- Product data fetched from DummyJSON API

## Tech Stack

- React
- Vite
- Bootstrap
- React Bootstrap
- Bootstrap Icons
- React Router

## Installation

1. Clone the project:
   ```bash
   git clone <your-repository-url>
   cd AMITProject
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Known Issues

- This project is designed for local front-end demonstration and role-based UI access.
- GitHub remote URL must be added manually after creating the repository.
- DummyJSON API is used for product and user data, so internet access is required for live data loading.
